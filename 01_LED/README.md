### 原理解释
- led流水灯的二进制解释：
1. 为什么 0 和 1 能控制亮灭？（硬件原理）
在大多数 51 单片机开发板上，LED 灯是共阳极接法（即 LED 的正极统一接 VCC/5V，负极分别接到单片机的 P2.0 ~ P2.7 引脚）。
写 0（低电平）：引脚相当于接“地”，电流流通，LED 亮。
写 1（高电平）：引脚电压与 VCC 相同，没有电压差，没有电流，LED 灭。
2. 二进制与引脚的对应关系
C 语言中的 0xFE 是十六进制，转换成二进制就是 1111 1110。
单片机 P2 端口正好有 8 个引脚（P2.7 ~ P2.0），一个字节（8个bit）刚好一一对应：
P2.7 -> P2.6 -> P2.5 -> P2.4 -> P2.3 -> P2.2 -> P2.1 -> P2.0 （引脚）
1 -> 1 -> 1 -> 1 -> 1 -> 1 -> 1 -> 0 （对应的二进制位）
所以，当执行 P2 = 0xFE; // 1111 1110 时：
P2.0 得到了 0，所以接在 P2.0 上的 LED 亮起。
其他 P2.1 到 P2.7 都得到了 1，所以其余 LED 全部熄灭。

-有无符号：
对于这张图片 有无符号 的解释：在 C 语言（包括 C51）中，“有符号”和“无符号”最核心的区别在于：**最高位（最左边那一位）是否被用作“正负号”的标志位。**
1. 无符号（Unsigned）
含义：所有的格子都用来装“数字大小”，**没有负数**。范围是从 0 开始的正数。
例子：表格里的 8 位 `unsigned char`。
 8 个格子全用来装数字，能表示的最大值是 `1111 1111`（即二进制的 255）。
 所以范围是 **0 ~ 255**。
生活中的比喻：就像计步器，只有 0 步、100 步，没有“负 100 步”。
2. 有符号（Signed）
含义：因为要表示负数，所以必须**借走最左边的一个格子**作为“符号位”（0 代表正数，1 代表负数）。剩下的格子才用来表示大小。
例子：表格里的 8 位 `(signed) char`。
最左边 1 个格子当了符号位，剩下只有 7 个格子表示大小。
所以它的最大值只能是 `0111 1111`（即 127）。
而负数部分有一套专门的算法（补码），能表示到 `-128`。
所以范围是 **-128 ~ 127**。
生活中的比喻：就像温度计，有零上 10 度，也有零下 10 度。
