##预备知识
1.扫描的概念
-数码管扫描（输出扫描）
原理：显示第1位→显示第2位→显示第3位→……，然后快速循环这个过程，最终实现所有数码管同时显示的效果
-矩阵键盘扫描（输入扫描）
原理：读取第1行(列)→读取第2行(列) →读取第3行(列) → ……，然后快速循环这个过程，最终实现所有按键同时检测的效果
**以上两种扫描方式的共性：节省I/O口**
-I/O口是什么
-Input/Output（输入／输出） 的缩写，意思是：单片机用来读取外部信号、控制外部设备的引脚。
例如：P2 表示一组 8 位端口，`P2_0` 表示这一组中的一个引脚。 图中所说的“减少 I/O 口占用”，主要指减少使用的引脚数量。
把按键接成矩阵，可以用更少的引脚识别更多按键。 矩阵键盘：I/O口从16个减少到8个
